## Provider order and seed
SettingsProvider > AuthProvider(initialRoster={createInitialRoster}) > StageThemeProvider > ProgressProvider > App.
A exports async createInitialRoster(): Promise<InitialRoster> plus initialSchoolGroup and demoStudents (hashed credentials only). AuthProvider calls factory only if there are no saved schools. Demo four remembered cards are created by AuthProvider. Do not persist literal PINs.

## Utilities
- hashPin(pin,salt), verifyPin(pin,hash,salt),generateSalt(). PBKDF2-SHA256 10,000 iterations and 16-byte salt.
- playChime,playWoodenTap,playFanfare,playSiren; global sound preference already applied.
- speakText(text,{stage?,rate?,onWord?(index),onEnd?(),onFallback?(text)}):boolean; stopSpeech();tokenizeWords(text):string[]. Word spans join with spaces and .active-reading by index. Returns false with visual fallback if unavailable; do not fake audio. Clean speech up on unmount. Speech begins with onWord(-1) and onFallback(text), retaining plain text with no current word until a native word-boundary event supplies an index. Platforms without boundary events remain unsynchronized throughout; no fabricated timing is used.
- computeAccuracy(correct,total),computeWpm(totalChars,elapsedMs),computeNetWpm(totalChars,uncorrectedErrors,elapsedMs),updateStreak(streak,correct),starsForAccuracy.
- storageEngine exposes loadProgressSync(studentId),loadProgress(studentId),getOfflineMutationQueue(),flushOfflineMutationQueue(), readStored/writeStored plus account helpers. Use contexts for UI writes.
- brownoutManager preserves synchronous getBrownoutSnapshot(studentId) and adds getBrownoutSnapshotAsync(studentId): local-first, IndexedDB fallback, same student identity/two-hour age/one-minute future tolerance validation. ProgressProvider ignores results from previous students or disposed effects and invalidates pending offers on resume/dismiss.

## Completion ID convention (confirmed from C/D implementations)
Tech lessons persist the exact `Lesson.lessonId` (for example `LES-1.1.1`). English vocabulary, sentence exercises, and stories persist their exact source `id` (`L1-01`, `SB-L1-01`, `RP-L1-01`); no additional prefix. Simulator completion IDs are `sim-tap`, `sim-mouse`, `sim-files`, `sim-shortcuts`, and `sim-scam` and are excluded from curriculum completion percentages. Portal percentages match completed IDs against the student's current assigned course data, deduplicate with a Set, and show completed/total counts. Tech matches grade and highschool bridge flag; English matches the derived five-track level. Label the metric current course; switching tracks changes its denominator without erasing previous work.

## Component boundary
All module entry files export BOTH named and default, accept no required props:
TechModule, SimulatorContainer, EnglishModule, TypingModule, GamesModule. Optional props fine. App lazy-imports defaults and selects view via ModuleKey. Components use core hooks rather than root-specific props. Each simulator exports named and default and accepts optional onComplete():void. Children import their own siblings directly.
B owns Header, BrownoutBanner, StageContainer interfaces internally and App/main. B can read other lanes for integration but never edit them. SVG components each named+default with optional React SVGProps<SVGSVGElement>. C/D may use own inline SVG or shared artwork, avoid hard dependency on unfinished art.
